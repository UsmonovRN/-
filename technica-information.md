На платформе Claude есть функция подключаемых навыков (Skills)-  загрузить навык можно только в формате ZIP-архива
constitution  хранитя в  Claude  тут :  Projects -> New Project -> Set project instructions
Включение кода: зайти в Settings -> Capabilities и включить тумблер Code execution and file creation
в раздел Project knowledge загружаются файлы знаний (документ требований, силлабус, протокол обзора)
Загрузка навыка (Skill): Customize -> Skills -> Create skill -> Upload a skill и загрузить ZIP-архив, внутри которого лежит skill.md (и alpha.py для уровня с кодом). После загрузки обязательно включить переключатель (тумблер) навыка, иначе он не запустится. Навык привязывается к аккаунту целиком, а не к отдельному проекту.
Техническое правило оформления ссылок на справку Claude: так как веб-документация Anthropic постоянно обновляется и не имеет даты выпуска, при ее цитировании в работе обязательно указывается дата прочтения.
